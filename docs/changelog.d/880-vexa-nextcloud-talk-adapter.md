- **Nextcloud Talk rooms can now be recorded/transcribed by the meeting bot (#880).** The bot joins a self-hosted Nextcloud Talk room (`https://<host>/call/<token>`) as a guest via a new `@vexa/join` adapter, then rides the mixed capture lane (WebRTC audio + pyannote) like Zoom/Teams/Jitsi. Pass `platform: "nextcloud_talk"` with an explicit `meeting_url`, and declare the deployment host in `VEXA_NEXTCLOUD_HOSTS` so pasted links and calendar (ICS) entries resolve to the platform.
